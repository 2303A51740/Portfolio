## 💻 How to Run Locally

Because this is a pure static website:

1. **Option 1 (Direct)**: Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, Firefox, or any modern web browser.
2. **Option 2 (VS Code Live Server)**: Right-click `index.html` inside VS Code and select **"Open with Live Server"**.
3. **Option 3 (Python One-Liner)**:
   ```bash
   python -m http.server 8000
   ```
   and visit `http://localhost:8000`.

*No `npm install`, no `npm run build`, and no development server are required!*
